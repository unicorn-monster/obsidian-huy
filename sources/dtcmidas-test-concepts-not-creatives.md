title: "Test concepts, not creatives, and stop caring which variation eats the spend"

I don’t really care about individual creatives eating all spend.

Let me explain. 

I test in a CBO with min spend, same holds for ABO.

Each adset gets 3-5 variations of one core concept (one big idea).

The variations are intentionally similar:

- Videos: Same body, different hooks
- Statics: Same headline, different visuals

My hypothesis isn’t “will this specific creative work?”

It’s “will this concept work?”

I don’t care if one creative in the adset eats all the budget because I’m getting the answer to my concept hypothesis.

If the concept works, I know I’m onto something.

If it doesn’t, I move to the next concept.

Once I find a winning concept, then I isolate variables, to extract more learnings.
