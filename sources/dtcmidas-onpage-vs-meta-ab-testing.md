title: On-page AB testing tools vs Meta for bigger tests
---

Smaller on-page tests, like specific sections, reviews, scarcity elements, product page carousels, copy (not hero & headlines)

I would run through A/B testing software like intelligems/elevate.

Bigger tests, like a full-on hero section with different headlines, new landing page formats, new product pages, offers I would run through meta
