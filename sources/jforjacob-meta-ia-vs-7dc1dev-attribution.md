I've seen a lot of people argue about incremental attribution vs 7DC1DEV attribution on Meta

Here's my take and what i've found after experimenting a lot over the past 4-5 months

- Any form of cost controlled campaigns will spend more if using IA and still hit roughly the same targets

- If you have two identical ad sets in a lowest cost CBO but one is using IA attribution and the other not, the one with IA attribution will spend more but have worse performance

- In platform reported CPA tends to line up much closer to first click attribution on triple whale with ads using IA

So how I'm using it and why:

For any new ads being tested we use IA. Reason is simple. We use TROAS in our testing campaign and new ads tend to always spend with this while using IA

And because no matter what style of ad you introduce to a testing campaign, new visitor % will always be pretty darn low. So having the IA, knowing that it lines up better with first click attribution makes sense here in terms of Meta optimising towards what you want. All the new ads pretty much retarget pretty heavily so if you know that IA is gonna optimise more towards being buying off first click it means you won't get as many false signals in testing

For regular scaling campaigns we run on lowest cost so stick with 7DC1DEV knowing that IA performs worse for us on lowest cost bidding

Graveyard campaign we also run on IA attribution for the same reasons as the testing campaign

Would encourage people to test this out it's been working great for us
