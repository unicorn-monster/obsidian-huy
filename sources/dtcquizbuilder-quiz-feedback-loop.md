Any good quiz is built on strong feedback loops.

Build the quiz --> Launch --> data

Then you find the weak points

Q1 drop off too high? (above 70%)
- Positioning Problem
- Mismatch in ad congruency
- Poor question framing

Drop off in the quiz is too high? (over 30%)
- You're not asking the right questions

Completion to purchase rate too low? (below 20%)
- Lack trust to buy
- Not convinced it will work
- Offer is not aligned with the questions asked

Generally if you pick each of these apart, create a hypothesis, test it, then come back to the drawing board

Your quiz will start scaling
