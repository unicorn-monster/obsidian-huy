title: "Never split test a new landing page at the site level straight away"

My process for testing landing pages:

- take top 3-5 existing ads for the angle you're testing (if general page just top 3-5 ads) and put them in a single ad set in an ABO campaign and send to new landing page. This is really just to get a quick check to make sure it's not terrible before risking a lot of traffic to it

- let this run for a few days, if it looks promising take your top ad inside your main campaign, duplicate it in the same campaign and send to the landing page

- See if it picks up spend and starts to outperform the original ad going to the original page

- If it passes this test, I'll start publishing all my new ads with 2 versions. One version going to the original landing page, the other version going to the new landing page

- If I see the new ads going to the landing page are consistently outperforming the original page I'll start publishing all my new ads only to the new landing page

- At this point you should have enough traffic going to the landing page to justify split testing headlines, copy, images etc

- Squeeze as much as you can out of the page with split tests and then repeat the process

I don't like just split testing a landing page at the site level straight away because if it's shit and you're sending 50% of your traffic there you could end up eating a big fat L

Same reason I don't just like duplicating a top ad and sending to the landing page without first doing a quick pulse check on it in ABO. Facebook will likely spend quite a lot on it even if the page is bad because it already knows and likes the creative. Again, big L risk

This is what I've found works best for me after doing it every way imaginable
