title: Subject line AB test rule clicks vs orders
---

If you're testing for orders, don't crown a winner because it got more clicks.

Decide what you're measuring before sending. Give both versions the same amount of time. If there isn't enough evidence to choose, keep your current subject line and plan the next test.
